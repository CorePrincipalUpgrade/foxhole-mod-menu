## 🧩 About

**Foxhole Mod Menu** is a curated list of Foxhole open-source tools:

- **Overlays** — on-screen helpers, layout notes, map viewer, region tracker
- **Quality-of-Life Helpers** — inventory catalog, logi notes, overlay helpers
- **Research Notes** — front-line layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Map Overlay — study hex layouts and region borders
- Base Tracker — organize stockpile and facility notes
- Logi Planner — plan supply routes for review
- Playback Notes — record and review session runs

### Wallhack
- Item Catalog — browse uniforms, vehicles, and equipment notes
- Custom Loadout Notes — organize kit presets
- Visibility Helper — improved marker visibility

### Aimbot
- Frontline Notes — segment study of each hex
- Facility Planner — manually plan production chains
- Comms Helper — chain complex coordination drills
